pinhook 2.0

IRC bots in plain Python.

Write a plugin as a function or a class, type its arguments, and pinhook handles the network, the rate limits and the permissions. Works on any IRC network, and on Twitch.

A plugin

A class, a decorator, a reply.

Plugins get a ctx with everything they need: who spoke, where, how to reply, a store that survives restarts, and their own settings.

Typed commands in the docs → 
import random

from pinhook import Plugin, command


class Dice(Plugin):
    @command('roll', help='roll dice, like roll 2 20')
    async def roll(self, ctx, count: int = 1, sides: int = 6):
        rolls = [random.randint(1, sides) for _ in range(count)]
        await ctx.reply(f'{ctx.nick} rolled {sum(rolls)} {rolls}')
# recipes/gamenight.yaml
version: 1
name: gamenight
help: pick tonight's game and who goes first
steps:
  - command: 'quote random games'
    save: game
  - reply: 'Tonight: {game}. {members|random} goes first'

A recipe

Custom commands, no code.

Recipes run existing commands as the person who asked, so a recipe can never do more than its user could. Ops add one-line recipes from chat with !recipe add.
