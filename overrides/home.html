pinhook 1.12

IRC bots in plain Python.

Write a plugin as a Python function, and pinhook handles connecting, joining channels, ops, bans and getting your replies back to the right place. Works on any IRC network, and on Twitch.

Get started $ pip install pinhook
#games
22:40 <ana> !hello 22:40 <pinhook> hi ana! 22:41 <mal> !roll 2d20 22:41 <pinhook> 14, 17 = 31 22:41 <mal> !roll lots 22:41 <pinhook> mal: improper format, should be NdN+N

What it does

Everything a bot needs, nothing it doesn't.

01

Plugins are functions

Mark a function with @command or @listener and return a reply. Drop the file in your plugins folder, and !reload picks up changes.

02

Ops and bans

Bot operators and bans by nick, hostmask or services account. Account bans follow people across nick changes and restarts.

03

Saved data and settings

msg.store is a dict kept between restarts, and msg.config holds the plugin's own settings from the config file.

04

Config files

Run a bot from a JSON, YAML or TOML file with the pinhook command, reading secrets from environment variables.

05

Logins and TLS

SASL or NickServ logins, checked TLS certificates, bot mode, and a new nick when yours is taken.

06

TestBot

Test plugins with pytest, no server needed. Stores live in memory and a plugin error fails the test.

A plugin

A function, a decorator, a reply.

A plugin gets the message: who sent it, where, a way to reply, a store that survives restarts and its own settings.

Writing plugins → 
import pinhook.plugin

@pinhook.plugin.command('!hello')
def hello(msg):
    return pinhook.plugin.message('hi {}!'.format(msg.nick))
from pinhook.testing import TestBot

def test_hello():
    bot = TestBot(plugin_dir='plugins')
    assert bot.say('!hello', nick='ana') == ['hi ana!']

Testing

Test it without a server.

TestBot runs your plugins the way a real bot does and hands back what it would have said, so a plugin's tests run in pytest like any other code.
