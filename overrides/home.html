pinhook 1.12

IRC bots in plain Python.

Write a plugin as a Python function, and pinhook handles connecting, joining channels, ops, bans and getting your replies back to the right place. Works on any IRC network, and on Twitch.

Get started $ pip install pinhook

What it does

What pinhook handles for your bot

You write the plugins. These are the parts pinhook takes care of, each with the page that covers it.

Commands and listeners

@command('!roll') runs when a message starts with !roll. A @listener sees every other message, /me actions too. Reply by returning message() or action(), or call msg.reply() as you go.

Who can run what

List ops by nick, hostmask like *!*@203.0.113.7, or services account like $a:mal. ops=True keeps a command to them. Bans made with !ban are saved to ban_file and last through restarts.

Bans and ops →

Data that survives restarts

msg.store is a dict pinhook saves as JSON after each plugin call. msg.config is the plugin's section of plugin_config, with a shared section for settings several plugins use.

Writing plugins →

Config files and secrets

pinhook config.yaml starts a bot from a JSON, YAML or TOML file. ${NAME} fills in an environment variable, so passwords stay out of the file. bot_dir keeps plugins, data and logs in one folder.

Getting started →

Logging in and TLS

sasl_password logs in with SASL, with ns_pass for NickServ as the fallback. ssl_required connects over TLS and ssl_verify checks the certificate. Connection errors are logged with what to fix.

Options →

Built-in commands

!help, !reload for new plugin code without a restart, !enable and !disable, !join and !quit, plus !op, !ban and !banlist for ops. cmd_prefix changes their !.

Built-in commands →

Testing

TestBot(plugin_dir='plugins') runs your plugins without a server. bot.say('!roll 1d1') returns the replies, and a plugin that raises fails the test with a PluginError.

Twitch

TwitchBot connects to Twitch chat with a bot account's oauth token, always over TLS. Plugins, ops and bans work the same as on IRC.

A plugin

A function, a decorator, a reply.

A plugin gets the message: who sent it, where, a way to reply, a store that survives restarts and its own settings.

Writing plugins → 
import pinhook.plugin

@pinhook.plugin.command('!hello')
def hello(msg):
    return pinhook.plugin.message('hi {}!'.format(msg.nick))
from pinhook.testing import TestBot

def test_hello():
    bot = TestBot(plugin_dir='plugins')
    assert bot.say('!hello', nick='ana') == ['hi ana!']

Testing

Test it without a server.

TestBot runs your plugins the way a real bot does and hands back what it would have said, so a plugin's tests run in pytest like any other code.
